Every kind of block.

Cards, charts, tables, forms and media all build the same way: a cursor drags the box, then the block fills in.

Or wire it yourself

Copy src/swarm-build.js into your project, mark your blocks, and call it once the page has loaded. No dependencies, no build step.

<h1 data-swarm-block>Hello</h1>
<script type="module">
  import { swarmBuildPage } from "./swarm-build.js";
  swarmBuildPage();
</script>
  • Page mode, swarmBuildPage(), rebuilds the live elements of a page, block by block, like this one.
  • Image mode, swarmBuild(img), builds a screenshot region by region, for a hero or product shot. See it on a screenshot.

Options

OptionDefaultWhat it does
speed12 builds twice as fast
typeSpeed1Speed of typed-in text, page mode
start"now""visible" waits until it scrolls into view
agents6 cursors[{ name, color }] in your palette
zIndextopLower it to keep a header or panel above the cursors
onDonenoneCalled once when the build completes

Every swarm returns

finished
A promise that resolves however it ends
finish()
Jump to the built page
destroy()
Stop and undo everything, for unmount
setSpeed(n)
Change speed mid-build
